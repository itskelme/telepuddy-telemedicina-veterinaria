# TelePuddy

Case study de uma plataforma de **telemedicina veterinária**: tutores marcam e fazem consultas online com veterinários.

## Telas

- Login e cadastro (validação de formulário e máscaras de entrada)
- Agendamento de consultas
- Sala de atendimento com indicador de áudio

## Tecnologias

Next.js 14 (App Router), TypeScript, Tailwind CSS, NextAuth, React Query, Redux e React Hook Form.

## Como rodar

```bash
npm install
cp .env .env.local   # API_URL aponta para a API do backend
npm run dev
```
